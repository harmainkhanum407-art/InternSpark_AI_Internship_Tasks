# GitHub Upload Guide

1. Create an empty GitHub repository, for example:
   `internspark-ai-internship-tasks`

2. Open this project folder in VS Code.

3. Open PowerShell in the project folder and run:

```powershell
git init
git add .
git commit -m "InternSpark AI internship tasks 1 3 and 4"
git branch -M main
git remote add origin YOUR_GITHUB_REPOSITORY_URL
git push -u origin main
```

4. Check GitHub and confirm `.venv/` is NOT uploaded.

5. Submit the repository URL together with the three task document links as required by InternSpark.
