InternSpark Artificial Intelligence Internship

Project title:
Responsible AI Analysis for Customer Churn Prediction

1. Objective
Analyze model interpretation and fairness-related diagnostics using feature importance, SHAP where supported, and subgroup metrics.

2. Model interpretation
The project calculates permutation feature importance on the original feature columns.

It also attempts a SHAP explanation using the fitted model and saves:
reports/shap_summary.png

3. Sensitive-group diagnostic
Gender is available in the dataset but is not used as a predictive feature in the main model. The analysis compares descriptive metrics across Female and Male groups.

Reported group metrics:
- Positive prediction rate
- Accuracy
- Precision
- Recall
- F1-score

4. Important interpretation
Differences between groups are diagnostic observations, not automatic proof of discrimination. They can be affected by sample size, data composition, feature distributions, model thresholds and other factors.

5. Mitigation recommendations
- Avoid unnecessary sensitive attributes in model features.
- Monitor subgroup precision, recall and positive prediction rate.
- Review threshold choices and error costs by group.
- Document data provenance and limitations.
- Re-evaluate fairness after major data or model changes.
